- Langues revendiquées : en, es, pt, fr, de, tr, uk, id, ja, zh-CN, zh-TW, ko, hi, ar, he ; `ar` et `he` en RTL.
- Parcours revendiqués : choix protocole, topologie, séquence, inspection, sélection événement, play/pause, précédent/suivant, vitesse, thème, progression.
- Présence dans des sources lisibles : HTML statique, noms des contrôles, assets compilés. **Le comportement de chaque combinaison n'a pas été observé ni validé en navigateur**.
- Hors périmètre : aucune preuve de capture réseau réelle ; les exemples doivent être étiquetés *simulations pédagogiques*.

## Stratégie de migration prudente

1. Conserver les fichiers historiques inchangés tant que la chaîne de propriété n'est pas clarifiée, sans les considérer comme réutilisables.
2. Construire une expérience indépendante `/observatory/` avec code TypeScript original et données modélisées, puis tester ses invariants.
3. Comparer protocole par protocole et locale par locale avec la référence ; compléter les manques documentés.
4. **Ne pas basculer la page d'accueil ni publier une release distribuable** tant que P0, les traductions de scénario et les parités critiques restent ouverts.
